# 质控状态与多样品图表复核（2026-09-27）

## 范围和依据

- 本轮只改变用户可见的状态文本和图表分类，不更改峰分析、活度计算或质量门。
- 四语言状态显示保留 JSON 原始状态码；`ready_for_quantification`、`conditional_result`、`blocked` 分别翻译，未知码显示本地化的“状态未知”。
- 已检出且正值：可报告值用深色柱，条件性估算用浅色描边柱；阻断、未检出和非正值均无柱。表格正式值仍只读取 `reportable_activity_bq_kg`。

## 样本与运行结果

1. 合成软件测试：`assets/app/tests/test_core.py::test_conditional_activity_chart_keeps_estimates_separate`。构造正常、条件性、阻断、未检出状态；检查正式/估算值进不同 Excel 列，四语言估算标签存在，PNG/PDF 可生成。合成样本只证明代码行为，不证明新土壤样品的定量准确度。
2. 用户此前提供的五份 `镭钍钾1.xls` 至 `镭钍钾5.xls`：仅把文件发送到本机 `127.0.0.1:8000/api/analyze`，使用内置刻度源和已提供的净质量 334、245、244、264、310 g 作图表状态烟测；不保存或再分发原始谱。返回顺序中，样品 1/3/4/5 均为 `conditional_result`，各有 3 个已检出正值条件性柱；样品 2 为 `blocked`，问题码 `blocked_calibration_failure`，不绘柱。由于标准源溯源、几何和基质未确认，四个条件性样品均不能据此宣称正式定量。此测试不构成独立盲样或参考值准确度验证。
3. `node --check assets/app/app/static/app.js` 通过；`python scripts/verify.py` 的 Python 编译通过，应用测试 **32/32**、Skill 判分器测试 **6/6** 通过；`git diff --check` 未发现空白错误。`127.0.0.1:8000/` 重启后返回 HTTP 200，静态脚本包含本轮状态与图表函数。

## 尚未证明

- 本地接口输出和合成导出通过，并不等于已在浏览器中完成五份原始文件的逐项目视验收；用户可在已更新的本地页面复核配色与布局。
- 样品 2 的阻断归因于项目能量刻度质量门；本轮没有改变该门或试图把它的估算值画成有效柱。
