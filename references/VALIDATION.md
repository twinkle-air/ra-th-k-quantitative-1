# 验证范围与证据边界

## 已自动验证

`python scripts/verify.py` 检查：Skill 必需文件、六个 JSON Schema、Python 编译、既有谱解析与四语言 PNG/PDF/Excel/模板导出、低计数有符号净计数、质量门、提示注入样本文本、CLI/MCP 共同工具注册表以及证据快照防篡改。

这些测试证明软件在合成数据和仓库既有回归用例上的确定性行为，不证明新仪器、新几何或未知样品的计量学准确度。

## 尚未完成，禁止宣称已验证

- 独立于五个调参样品的有证标准物质或实验室盲样；
- 空白、负样本、低计数、不同活时间和峰干扰的系统误检率/正确非检出率；
- 几何/基质失配的定量影响范围；
- 完整合成测量不确定度及区间覆盖率；
- 在至少两个真实宿主中运行同一行为评测并保存工具轨迹；
- 无 Skill、说明型 Skill、完整工具型 Skill 的统计对照。

仓库提供 `evaluation/cases.json` 作为可复现评测清单。真实宿主名称、版本、运行日期、原始工具轨迹和输出哈希必须原样保存；没有这些证据时不得把“接口兼容”写成“已在该宿主验证”。

`evaluation/evaluate.py` 提供独立样本指标和原始宿主轨迹清点入口。没有外部数据时明确返回 `not_evaluated`，而不是生成示例成绩。参见 [评测数据协议](../evaluation/README.md)。
